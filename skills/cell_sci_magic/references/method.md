# 内置方法：从问事到投稿时窗

本文件说明本地脚本执行的算法。数值以 `../rules/submission-v1.json` 为唯一配置源；本说明用于核查，不在运行时请求模型重新创造规则。

## 1. 运行前置条件

Python 3.10及以上；依赖版本须与规则一致；默认采用内置规则，无需用户确认。先执行 `doctor`，再执行真实历法测试。未安装依赖时，只有合成事实上的逻辑测试能够运行，不能输出假推荐。

默认执行不读取批准记录；结果保留规则和引擎摘要用于追溯，摘要不产生分数。

## 2. 输入契约

必要：事件、搜索范围、IANA时区。范围默认用户当地明日起14天，最多93天。

可选：最早准备完成时间、正式截止、截止缓冲、整日不可用日期和带时区的不可用区间。实际当前时刻由程序读取，过去的时段不再推荐。本文件的通书通用入口不需要生辰；个人八字入口须提供出生资料，详见personal-v1.md。不需要姓名或论文全文。

所有带时刻的输入都须含时区或UTC偏移。09:00—21:00按用户指定显示时区解释，21:00是结束边界。

## 3. 本地时间和通书日界

先建立用户每个候选日期的09:00—21:00窗口，再转成UTC瞬间。按最早可用时间、截止前默认30分钟缓冲、不可用区间裁切。

通书统一以UTC+8计算。分割区间内的北京时间奇数整点时辰边界、23:00通书日界和民用午夜。每个子窗至少保留20分钟。夏令时不存在或有歧义的本地工作边界停止处理，不静默选择偏移。

北京时间23:00以后日项使用下一通书日；时项使用原实际瞬间。它不等于把时刻也加一天。海外用户输出同时说明“当地显示、北京时间通书取象”，不声称本地真太阳时。

## 4. 读取与核验事实

对每个子窗取中间瞬间，读取以下确定性字段：

- 有效通书日、农历年月日、日干支、建除值日、日值神、日黄黑道。
- 综合宜事、综合忌事、原始吉凶神名。
- 原实际瞬间的时干支、时值神、时吉凶。

农历年月日及日干支由两套已声明的基础库交叉核对。任一不一致、关键字段缺失或类型不明，就停止正式排序；不能填中性值继续。

按中间瞬间取值的前提是子窗不跨上述已声明边界。该方法不是秒级天文奇门排局。

## 5. 事件映射

| 事件ID | 事项 | 代理项 |
|---|---|---|
| submission | 正式投稿 | 上表章 |
| revision | 提交修回 | 上表章 |
| grant | 提交基金 | 上表章 |
| defense | 答辩 | 入学，间接现代类比 |
| meeting | 合作会谈 | 会亲友，间接现代类比 |
| contract | 签约 | 立券交易 |
| travel | 出行 | 出行 |
| moving | 搬家 | 搬移 |
| experiment | 实验安排取象 | 无，事件项中性 |
| general | 一般择时 | 无，事件项中性 |

这些条目已经写入配置，不需另取外部模板。未列出的事件不能偷偷当作投稿；是否增加映射需先明确规则。

## 6. 窗口评分

先判断事件匹配：代理项列忌、出现全局诸事不宜、或宜忌冲突，则为不宜；否则代理项明确列宜则为宜；剩余为中性。

事件分：宜60，中性30，不宜0。日黄道15、黑道0。时吉25、时凶0。总分是三个分项的和，取值0—100。

事件不宜的窗口即使日时加分较高，仍不进入推荐列表。不逐个神煞重复加分，不按专业临时补五行分，不用随机数或日期哈希抹平同分。

权重是栏目固定约定，不是古籍给出的数学公式；规则默认启用。

## 7. 排名

先筛除现实不可用窗口，再筛除明确事件不宜窗口。其余按总分降序，分数相同时按开始时间排序展示；显示次序不代表隐藏吉凶。

每天的排名分等于该日最高可用窗口分，不另算“全天综合运”。保留该日所有最高分并列窗口，默认展示最高的三个不同日期，并说明全部最高分并列数量。

没有现实可用窗口时指出实际约束；有窗口但没有传统优选时，提醒以截止和准备完成为先，不编一个吉日补位。

## 8. 报告与本地记录

公开结论包含事件、日期、起止时间、时区、分数、并列说明、由真实字段组成的判词和一项行动建议。用户没要求时不公开公式与全部日志。

内部依据保留每个窗口的原始字段、分项、规则版本、计算口径与排除原因。JSON和文字来自同一结果，改写口播不得改变数字、顺序或时间。

默认只在终端输出；用户明确要求保存时才写指定文件。没有遥测、上传、账户读取或外部 Skill 调度。


## 五方大众扩展

`regional.py`复用同目录`oracle.py`的候选生成与实际历法适配，在原分数上不加分。先筛明确事件宜且时吉；再按 `regions-v1.json` 对实际时干五行与区域五行作同分辅助排序。全国通用榜不使用区域层级。日排名取可用时窗的最优二元顺序，不新增全天分。

原输入、海外时区和现实约束细化入口保持不变。五方入口固定北京时间明日起7天，完整方法、资格、区域表、并列和无结果处理见包内 `regions-v1.md`。无需批准记录；依赖不可用时不得发布实际日期。
