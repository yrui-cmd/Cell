# 投稿择日评分v1｜默认启用

## 默认规则内容

本规则是**确定性传统通书数据上的栏目排序规则**，不是随机抽签，也不是古籍原生百分制。当前默认启用，直接计算并输出真实日期推荐。

主场景：论文初投；同理覆盖修回和基金提交。现代投稿类比“上表章”。《协纪辨方书》卷十一确有该条及其宜忌，但未讨论学术期刊、审稿流程或录用率。

## 固定分项

总分=事件宜忌分+日黄黑道分+时神吉凶分，范围0—100。

| 分项 | 条件 | 分数 |
|---|---|---:|
| 事件取象（上限60） | 上表章出现在该日最终“宜”，不在“忌” | 60 |
| 事件取象 | 既未列宜，也未列忌；或该事件没有直接代理项 | 30 |
| 事件取象 | 上表章列“忌”，或诸事不宜；异常同时出现宜忌也从忌 | 0，并且不列推荐 |
| 日值（上限15） | 日黄道 | 15 |
| 日值 | 日黑道 | 0 |
| 时值（上限25） | 时值神为吉 | 25 |
| 时值 | 时值神为凶 | 0 |

**60/15/25由本栏目制定，非古籍给出的权重。** 以事件宜忌作为主要因素，日时黄黑道只作辅助；这是设计选择，不能说经过录用数据训练或科学验证。相关因子不是独立概率，分数也不是百分比成功率。

不逐个神煞重复加分，避免某日神煞名字多就分数高；不把“开市”偷换成“投稿”。使用库按其规则综合后的宜忌，完整保留原始神名用于核查。

## 固定排历口径

使用北京时间通书：`cnlunar` 农历月法、农历新年年界、23:00子初日界；时神用`lunar-python`的时值神接口。先核验农历日期与日干支，不比较两个库不同流派的全部宜忌，也不宣称精确奇门排盘。

海外将北京时间盘对应到用户当地09:00—21:00。它不是当地真太阳时体系。这是固定方法口径。

## 固定排序与并列

先过滤已过、未准备好、不可用、超21:00、过截止缓冲、持续时间不足20分钟的窗口。

明确事件“忌”的窗口只进入内部依据，不列为吉时推荐。其余按总分降序；同分照实保留，界面按日期先后显示，不将先展示解释成更吉。日排名使用各日最高可用窗口分，不捏造第二套日分。

这个离散评分可能多次同分，是正常现象。**不能添加随机个位数，把85分改成87分只为了好看。** 也不能改变权重让特定日期胜出。

## 固定时间精度

通常按北京时间两个小时的传统时段比较。时区换算、用户预约、最早准备完成时间、截止前30分钟缓冲都可能裁出带分钟的边界；必须说清它来自现实约束，不能宣传为“算到09:37最灵”。

如果没有传统优选，直接说明“范围内无传统优选，按现实条件及时提交”，不劝人错过截止；只有用户主动扩展日期范围时才重算。

## 默认执行

直接采用内置规则，无需用户确认，不创建批准记录。规则摘要只用于追溯，不产生分数。
