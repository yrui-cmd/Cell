# 输出与验收

## 运行验收

在只含交付代码、必要输入和 profile 的新目录中重跑。记录实际命令、退出状态、Python/MATLAB 与主要绘图库版本。输出文件名、数量和格式必须与 profile 一致，不能依赖旧缓存或开发目录中的模块。

对输入和输出保存哈希用于版本识别。哈希变化说明需要复查，不证明两次渲染在科学或视觉上正确；PDF 时间戳等元数据也可能造成字节差异。

## 科学检查

- 数据点、样本量、分组、顺序、单位和图例映射与输入一致。
- 配对、重复测量、批次和层级关系没有在图中丢失或伪装成独立样本。
- 误差条、区间、n、P 值及校正方法含义明确；无推断统计时不制造显著性标记。
- 轴变换、归一化、缺失和排除规则与代码一致。
- 同一比较的面板使用可比较的尺度；截轴有科学理由且不会误导。

## 视觉检查

实际查看每种格式和最终插入页面，至少检查：

- 面板数量、顺序、比例、对齐和留白；
- 字体、上下标、单位、数学符号和最小文字；
- 线、点、柱、误差条、阴影和网格层级；
- 图例、色条、注释没有遮挡或裁切；
- 颜色语义一致，灰度和常见色觉差异下仍能辨认；
- PDF 中应为文字的内容可搜索/复制，线条和可矢量图元没有整图栅格化；
- PNG/TIFF 的真实像素、DPI、颜色模式和压缩符合当前要求；
- 多格式来自同一版本，标签、范围和数据完全一致。

## 文档集成

将正式图件按目标宽度插入真实稿件或最小可复现页面，至少编译/渲染两次。检查正文、图注、图号和面板引用；图中文字与正文在正常阅读比例下协调。

本 Skill 只为确认图件在目标页面中的表现做局部集成。若要解决整篇稿件的浮动体队列、分页、总页数或投稿包，转 `cell-submission`，不要靠负间距或压缩参考文献掩盖版面问题。

## 失败状态

未运行所选后端、缺真实输入、缺关键设计信息、无法查看最终输出或没有目标模板时，交付可完成部分并指出具体缺口。不得写“出版级”“已通过期刊规范”或“完全可复现”。
