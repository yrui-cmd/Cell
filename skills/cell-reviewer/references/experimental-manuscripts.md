# 实验性与原始研究论文审稿人

本参考用于实验、观测、计算、方法和数据资源论文。先识别实际研究设计，再从论文所作主张出发选择检查；不能把生命科学机制论文的证据要求普遍套给材料、工程、计算或资源研究。

## 主张与证据链

逐项区分描述、关联、预测、因果、机制、泛化与转化主张。对核心结论串起“研究问题 → 操作/测量 → 比较与对照 → 结果 → 解释”。检查证据能否区分关键替代解释，而不只问是否与作者假说相容。

| 检查面 | 改变判断的关键问题 |
| --- | --- |
| 贡献与公平比较 | 新结果/方法/资源相对恰当基线的差异是否清楚；比较的数据、预算、条件和调参是否公平。 |
| 设计与测量 | 对照、校准、量程、时点、剂量、随机化或盲法在该设计下是否需要且充分；结局和测量是否真能回答问题。 |
| 独立单位与重复 | 生物学、实验、技术重复及嵌套/配对关系是否清楚；不能把同一动物的视野、同一样本的孔或切片数当独立样本。 |
| 偏差与样本构成 | 选择/纳排、缺失、失访、批次、混杂、预设和事后分析是否影响中心比较；未报告与确实未实施分开。 |
| 统计推断 | 效应量和区间、估计目标、样本量依据、模型假设、重复测量/层级结构、多重比较、稳健性是否匹配；不能仅以 p 值判科学意义。 |
| 机制与因果 | 干预特异性、时间顺序、剂量反应、必要性/充分性、救援或正交证据是否与所声称机制匹配；不是所有稿件都需要全套证据。 |
| 可复现性 | 核心参数、材料身份、协议、数据处理、代码/版本、数据与代码访问路径是否足以复核关键结果。 |
| 外推与实际价值 | 验证对象是否独立，适用工况/人群/模型范围是否清楚；体外、动物或回顾性结果不能直接承诺人体疗效或真实部署收益。 |
| 伦理与来源 | 只在设计相关时检查伦理审批、同意、动物福利、材料来源、隐私及访问条件；未见声明是报告缺口，不是违规证据。 |

上述条目在内部标为适用、不适用或无法评估。只输出有稿件依据且影响评估的意见，不把整张检查表机械变成问题清单。

## 按设计启用的附加检查

- **细胞/分子实验**：关键试剂及细胞身份、干预特异性、适当阴阳性对照、批次与独立重复；仅在机制主张需要时建议遗传/药理正交验证或救援。
- **活体动物研究**：按 ARRIVE 2.0 的适用报告要素检查分配、实验单位、样本量、排除、盲法、结局和动物信息；评价性别、年龄等因素对所作外推的影响，不机械要求补齐所有模型。
- **人体随机试验**：查适用的当前 CONSORT 版本，核对随机化、分配隐藏、预设结局、分析集、依从/失访、效益与伤害及注册方案的一致性。规范勾选齐全不等于设计可靠。
- **观察性/临床预测研究**：混杂、选择偏差、时间顺序、数据来源和验证、校准及临床效用须与结论相称；适用时参考 STROBE 或设计对应规范，不把预测性能称为因果证据。
- **材料/工程实验**：制备与批间重复、校准和测试条件、负载/环境/边界条件、实际指标、耐久性与失效；只要求所声明用途需要的验证。
- **计算/机器学习**：训练/验证/测试隔离、受试者/时间/空间或近重复泄漏、选择偏差、公平基线、消融、随机性与计算资源。是否需外部验证由泛化主张决定。
- **方法/数据资源论文**：评价测量/标注有效性、覆盖与代表性、版本/质量控制、基准与复用价值；显著的方法或资源贡献不必附带全新的分子机制。

报告规范来源及适用范围见 [source-basis.md](source-basis.md)。不得将规范条目当作全学科通用的拒稿条件。

## 补实验或分析建议

每项建议写出：它修复哪个主张的哪处证据缺口；什么结果将支持或反驳解释；最低限度的可执行对照/分析是什么。区分以下类别：

1. **关键修复**：当前核心推断依赖该证据，需补现有数据分析、关键对照或验证；若可合法收窄/删除结论而不掩盖问题，应给出该替代路径。
2. **重要增强**：改善范围、稳健性或复现性，说明对结论的具体影响。
3. **可选扩展**：有价值但超出当前中心问题，不列作接收条件。

不以“再加组学、动物、人样本”作为默认方案；不为满足机械数量要求堆叠实验。不要求不当的事后功效分析来证明阴性结论，以设计依据、效应区间和推断边界评价。统计显著不等于生物/临床重要，未显著不等于等效。审稿任务不自动授权运行新实验或修改原始数据。

## 三份独立报告的预设重点

| 报告 | 侧重点，所有人仍覆盖共同轴 |
| --- | --- |
| R1 | 设计、对照、测量、机制/因果链和关键替代解释。 |
| R2 | 重复单位、统计与不确定性、数据来源、稳健性和复现。 |
| R3 | 贡献与基线、证据支持的泛化范围、读者价值、图表和结论表述。 |

这是工作重点，不得虚构专家姓名、机构、资历或期刊委派身份。
