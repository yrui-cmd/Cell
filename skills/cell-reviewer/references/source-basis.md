# 来源与标准边界

## 改编来源

本技能由 2026-10-08 本地已安装的 `nature-reviewer` 及其审稿流程、技术问题分类、一致性核查规则改编并用中文重新组织。上游为 [Yuan1z0825/nature-skills](https://github.com/Yuan1z0825/nature-skills/tree/main/skills/nature-reviewer)，许可见包内 `LICENSE`；改动说明见 `NOTICE`。不需要运行时安装 Nature 系列。

沿用的工作机制包括独立报告后再综合、证据定位、按影响校准 Major/Minor、审后核算及不虚构审稿人。新增综述四类分流、跨学科原始研究模式、最小充分修订与单报告边界。未把 Nature 的文章筛选门槛或其标点习惯当作所有期刊规则；没有把该实现宣称为 Cell Press 官方审稿程序。

## 外部规范按需使用

以下链接是标准入口，不要求每次把所有清单加载。2026-10-08 核查；遇到特定期刊、版本或强制性要求时以当时官方说明为准，报告采用的版本与适用范围。标准网页无法访问时说明未核验，不猜要求。

| 来源 | 类型与用途 | 适用边界 |
| --- | --- | --- |
| [PRISMA 2020](https://www.prisma-statement.org/prisma-2020) | 系统综述报告规范 | 清单完整不等于方法有效；需要时查设计对应扩展。 |
| [PRISMA-ScR](https://www.prisma-statement.org/scoping) | 范围综述报告规范 | 不强制所有范围综述做疗效合并或偏倚风险评价。 |
| [SANRA 原始研究](https://doi.org/10.1186/s41073-019-0064-8) | 非系统/叙述性综述的质量评价工具 | 源自医学综述情境；借鉴判断维度，不推广为跨学科强制总分。 |
| [AMSTAR 2](https://www.amstar.ca/) | 卫生干预系统综述的方法学评价工具 | 不机械套用任意领域、诊断或范围综述。 |
| [ARRIVE 2.0](https://arriveguidelines.org/arrive-guidelines) | 活体动物研究报告规范 | 不是所有实验论文通用清单，也不是伦理审批证明。 |
| [CONSORT 2025](https://www.consort-spirit.org/published-statements) | 随机试验报告规范 | 与方法学质量独立判断；审稿时核对当前版本及适用扩展。 |
| [STROBE](https://www.strobe-statement.org/) | 观察性流行病学报告规范 | 不赋予观察性数据随机试验的因果识别能力。 |

具体科学事实以用户稿件及实际读取核实的原始研究为准；期刊格式/流程要求以所选期刊官方来源为准；本技能的报告数量、意见 ID、共识门槛和优先级是本地工作约定，不是期刊政策。
