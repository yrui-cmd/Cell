# 审后的一致性核查

个体报告冻结后由主审执行，不是第四份审稿意见。单报告也执行适用检查。只对可读、可定位的材料进行验证，不为每篇论文要求相同项目，也不把未执行的检查标为通过。

区分稿内一致性核查与方法学判断：对方法适用性或科学解释的评价仍属审稿意见；只有找到可定位的内部矛盾或可复算错误，才另列“已证实内部错误”。把一条意见再读一遍不构成额外验证。

## 有数据时的可复算检查

- 组别、纳入/排除、样本和百分比能否对上；综述分别核对记录、报告、独立研究/队列与分析数量，按流程阶段核对，不将不同单位强行相加。
- 摘要、正文、图表和补充材料中的主结果、单位、分母、时间点及精度是否一致。
- 增减量、倍数、区间、极值和排名陈述是否与所示数值相符；将复算表达式或中间数保留下来。
- 概率、比例、指标界限先查定义与聚合层级；宏/微平均、患者/图像层面或不同归一化可以解释差异时，先列歧义，不能直接判错。
- 独立重复、技术重复、配对/嵌套结构与统计样本数是否一致；森林图中效应方向、权重和共享对照是否与方法相符。
- 训练/测试、中心、时间、样本来源或同一队列复用是否影响独立性；没有样本标识或来源信息时不能宣称已排除泄漏。

简单算术可直接列式；较复杂复算用可重跑的本地代码，保留输入和容差。只有图像或四舍五入值时承认精度限制，不猜原始值、p 值、效应量或元分析输出。

## 图表、引用和可复核性

- 检查图例、坐标/比例尺、误差类型、代表性图像与量化的对应。相似图像、重复行、异常小方差只能标“待核实”，不能仅凭视觉或模式判断造假。
- 未实际打开图像只能审图注；不声称完成图像真实性检测。
- 对中心综述断言抽查关键原始引用，区分全文、摘要与二手引用。未查到全文不能宣称“原文没有该结果”。
- 材料、代码/数据入口和版本可核查到什么程度就报告到什么程度。只有实际运行并对照输出才称复现；访问失败或缺少环境写无法核验，不等于复现失败。
- 除非用户授权并有必要，不为一次审稿启动昂贵复算、付费服务或上传原稿。

## 记录状态

| 状态 | 使用条件 |
| --- | --- |
| 已证实内部错误 | 可定位数值、文本或原始数据直接证明矛盾；展示证据。 |
| 定义/聚合歧义 | 结论取决于未说明的指标、分母、单位或聚合。 |
| 来源/复现信息缺口 | 不能追溯核心数值、样本或方法；不推断原因。 |
| 疑似重复/异常 | 可疑但证据不足，需原始记录或解释。 |
| 待补材料 / 无法评估 | 缺少数据、图像、全文或环境，尚不能判断。 |
| 已检查未发现矛盾 | 写明实际覆盖范围，不表示全稿真实性被认证。 |

每项输出 `AUD-01`、状态、位置、具体检查/计算、结果、影响和解决判据。与已有审稿意见重叠时列 ID；无人提及的错误仍必须呈现，但不得称共识。核查发现可以改变综合判断，不能反向喂给独立审稿人来制造一致。
