# 综述审稿人

本参考只在审阅综述或混合稿件的综述部分时读取。综述贡献可以来自概念框架、冲突解释、证据整合和可检验的研究议程，不以新增湿实验为必要条件。

## 先确定综述类型

| 类型 | 核心验收点 | 不应机械要求 |
| --- | --- | --- |
| 叙述性/批判性综述 | 问题和边界清楚、选文理由透明、代表性与反证兼顾、形成自己的分析 | PRISMA 流程图、预注册、双人筛选、穷尽检索、Meta 分析或新增实验不是统一门槛。 |
| 系统综述 | 可复现检索与选择、明确纳排标准、偏倚风险处理及可信综合；用 PRISMA 2020 等适用规范检查报告 | 有流程图不等于方法可靠；未注册不自动等于结论无效，应查协议、时间线、偏离及实际影响。 |
| 范围综述 | 问题范围、证据选择/数据绘制透明，图谱与空白识别相符；参考 PRISMA-ScR | 不自动要求定量合并或疗效定论；质量评价是否需要取决于目的和声明。 |
| Meta 分析 | 继承其证据选择框架，再审合并对象、效应定义、依赖结构和不确定性 | 不因研究数多就宣称可靠，不要求不适用或无足够研究支持的发表偏倚检验。 |

作者声称“全面”“系统”但方法只支持选择性叙述时，定位这个不匹配，要求说明范围、补充可复现方法或调整标签；不要自行替作者把稿件改为另一种文章。

## 所有综述共有的判断

1. **问题与新增价值。** 中心问题、时间/人群/领域边界、受众是否明确；相对直接可比综述的新增框架、综合或证据是什么。不能联网查新时不凭记忆判“无创新”。
2. **证据选择。** 核心论断是否追溯到适当的原始研究；经典工作、近期进展、负结果、冲突结果和其他学派是否按相关性覆盖，而不是按数量或年代配额补引。引用倾斜必须以已核查的遗漏或错误归因证明。
3. **综合而非堆砌。** 是否比较设计、样本/模型、测量和边界，解释结论为何不一致；分类框架是否能解释证据，而不只是把论文分组排列。
4. **证据等级与推断。** 区分体外、动物、观察性、随机试验、计算预测与假说。不得把相关性、局部现象或示意图中的箭头升格为已证实机制/疗效。
5. **平衡性与不确定性。** 区分“没有研究”“研究未发现效应”“证据不确定”；作者偏好、利益冲突或引文倾向可以核查，不能凭行文风格指控。
6. **图表与研究议程。** 综合表应支持跨研究比较并标出处；机制图注明证据强弱。未来方向应对应已识别的缺口，能说明需要什么证据，不只写泛泛的“更多研究”。

叙述性综述可借鉴 SANRA 的选题重要性、目标、检索描述、引用、科学推理和数据呈现维度；它不是适用于所有学科的统一评分或期刊拒稿阈值。不以清单总分替代实质判断。

## 系统综述与范围综述的额外检查

- 核对问题与研究设计，数据库/其他来源、完整检索式、各库检索日期及更新截止时间、语言/年份限制和理由。
- 核对记录、报告与独立研究的单位，去重、筛选及排除过程是否可追溯；多篇论文来自同一队列不得当作独立研究重复计算。
- 核对协议或注册及偏离披露、筛选/提取与分歧处理。缺少某一形式步骤时说明影响，不机械认定科学无效。
- 系统综述的方法学偏倚评价和证据确定性应匹配问题、设计与所作结论；PRISMA 是报告规范，不是方法学质量评分。AMSTAR 2 仅在其适用的卫生干预综述范围内使用。
- 范围综述区分“地图中未覆盖”和“领域不存在”，谨慎处理疗效或因果推断；不因没有偏倚风险评价就默认不合格。

## Meta 分析的额外检查

- 效应量、方向、单位、对照、结局和随访时点是否可比；合并人群和研究设计是否有科学依据。
- 多结局、多时间点、多组共享对照、重复队列的相关性是否处理；模型、权重、方差及零事件处理是否匹配数据。
- 检查临床/方法异质性及统计异质性，不能仅凭 I² 阈值选择模型；随机效应不能自动解决不宜合并的问题。
- 关注影响性研究、敏感性分析、亚组/元回归与多重比较；少量研究时承认小样本和发表偏倚检验能力有限。
- 区分无统计学显著差异与等效/无效；结论需考虑偏倚、精确性和间接性。只在有数据或足够汇总量时复算，不从森林图像素虚构精确值。

## 三份独立报告的预设重点

| 报告 | 侧重点，所有人仍覆盖共同轴 |
| --- | --- |
| R1 | 问题边界、综述增量、概念框架与批判性综合。 |
| R2 | 检索与证据选择、原始来源支撑、偏倚及适用的定量合成。 |
| R3 | 冲突解释、证据到结论的跨度、图表可读性、实际价值与未来研究议程。 |

这是工作重点而非真实审稿人身份。每条意见应给出最小可行修订，例如补查具体证据分支、重构一个比较维度、纠正某项提取或收窄结论；不要把审稿变成重写整篇综述。
