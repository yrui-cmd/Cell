# 逐页质量检查

本检查只用于发现可见的翻译与版式问题，不把图片生成结果认证为逐字准确。源页和中文页都必须实际打开；只看文件名、缩略图或脚本成功状态不能填写 `pass`。

## 检查顺序

1. **区域完整性**：标题、作者、摘要、正文各栏、图表、图注、脚注、页眉页脚和本页截断片段是否仍在相应区域；有无整段遗漏、重复、错栏或新增内容。
2. **科学保真**：数字、正负号、单位、统计量、变量、公式、上下标、引用编号、DOI、图表数据点、坐标范围、图例对应和子图顺序是否发生可见改变。
3. **翻译对应**：动作、对象、条件、否定、比较、因果强度和先后顺序是否与可辨认原文一致；缩写与术语是否前后一致。
4. **版式可读性**：源页尺寸、方向、裁切、分栏、区域边界和阅读顺序是否保持；有无文字覆盖、裁切、异常空白、伪文字或过小字号。

只记录能从页面直接确认的事实。细小文字或复杂公式无法可靠核实时写 `unknown`，不根据常识补齐。

## 登记格式

```json
{
  "status": "pass",
  "observations": [
    "已对照标题、双栏正文、图 2、图注、公式和页脚；在当前可见分辨率下未见明显缺失或区域错位。",
    "细小参考文献仅检查编号顺序，未进行逐字校对。"
  ]
}
```

- `pass`：检查范围内未见会影响阅读或科学含义的明显问题；观察必须说明覆盖范围。
- `issue`：发现可定位的内容缺失、科学字段变化、错栏、不可读文字或明显版式破坏；写清页内区域和影响。
- `unknown`：当前分辨率、源页质量或语言辨读不足以判断关键部分；写清未能核实的内容。

不要写空泛的“质量很好”“翻译准确”。内部报告可汇总状态，但最终只交付 PDF；存在 `issue` 或 `unknown` 时在交付句列出相应原页码。
