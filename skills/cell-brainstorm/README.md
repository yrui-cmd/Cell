# cell-brainstorm v2.0.0

单个模型；六步进度；最终为五个选题的简明学术论证稿。

## 使用
解压后保留 `cell-brainstorm/` 整个目录，放入宿主实际支持的 Skill 目录。不会自动安装或覆盖旧版本；升级前备份旧目录。不要仅复制SKILL.md并丢弃配套规则和脚本。

调用示例：
> 调用 cell-brainstorm。研究方向：铁死亡与肝硬化。已有资源：……。运行时仅显示第几步，最后按提交导师的格式给五个选题及文献依据、研究增量、实施方案和限制。

资源可不填；未知条件不会被虚构为已有。

## 你会看到
过程每步首次开始时只出现 `第1步` 至 `第6步`，然后提交五题论证稿。每题四个短段落，不展示分数、等级或审计表；实际研究依据和限制必须保留。平台工具卡片及权限提示不受Skill控制。

## 安装本地校验依赖
```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```
具体调用和真实运行建档见 `references/runtime.md`。网络检索和模型调用由现有宿主完成，本包不是独立联网研究服务，不包含第二模型。

## 完成本次升级的内容
六步外层/十四阶段内部；按研究类型定义可回答性；两轮发想；假设/结构类比合同；主动查重及反证；候选版本重新查新；三层执行路径和AND/OR资源依赖；最小验证四种决策；三道门；五题及共同风险；只显示步骤编号。新版schema、检查代码、渲染与测试已随包。

## 边界
`tests/validation_report.json` 记录本次实际测试，`tests/TEST_RESULTS.txt` 保留日志。测试为本地合成、结构、计算、CLI和打包检查；不等于真实文献语义、原创性、科研价值或模型一致性得到验证。没有自动进行任何动物/人体实验或昂贵分析。
旧schema1.1仅保留回放兼容，不代表符合本次增强合同。运行数据在RUN目录，旧压缩包未改动。
