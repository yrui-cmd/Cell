# 版本记录

## 2.1.0 — 2026-10-12
- 新增 `original_research` / `evidence_synthesis` 产物分流，综述选题不再被强制套入新实验可行性标准。
- 证据综合同时比较最接近综述与承重原始证据，记录可证伪的 `synthesis_delta`、候选层级关系和三维检索状态。
- 为证据综合增加独立审计合同、模板和确定性门槛；原始研究继续使用 2.0 schema，禁止用伪实验字段通过校验。
- 将 P0/P1/P2 分别解释为试综合、完整综合和可选扩展；开放科学问题不再自动阻断有边界的综述选题。

## 2.0.0 — 2026-09-27
- 合并最终六步主框架，保留S00–S13内部证据边界；每次同一个模型。
- 增强问题重构、结构类比、候选有界改造、三层执行路径、资源AND/OR依赖、四类最小验证决策和三道科学门。
- 主张版本变化须重新查新；已执行验证必须有实际记录，未知资源不冒充可用。
- 公共进度仅第1步至第6步，不重复；默认本地CLI静默。
- 公共报告改为提交导师的简明选题论证稿，五题四段、数字引文及参考文献；内部评分和审计不展示。
- 新增2.0 schema、增强检查、report_sections、正式文体排版、进度状态及回归测试。1.1仅保留回放兼容。
- 原1.0/1.1压缩包未覆盖。软件检查不等于科研质量验证，详见tests。
