# 单模型执行说明

## 一个模型，多个阶段，而非多个角色演员
本Skill只有一个宿主大模型。生成、自查和写作是这个模型在不同阶段完成的任务。
禁用多智能体编排、外部评审模型、多模型投票和隐式模型回退。检索数据库与本地Python不计作额外模型。
不能报告“专家A和B独立同意”，不能把重复调用次数当证据量。不得自动收集多位真人参与者贡献。

## 两种真实上下文条件
- same_context：同一对话继续。模型看过种子、自评分或排名时，应如实记录；不声称盲审。
- fresh_context：宿主确实支持同一模型的新上下文，只传当前阶段资料。可以减少提示级历史暴露，但不是独立模型，也不是外部领域评审。
若供应商仅提供动态别名，保存其实际返回标识；无法确认权重版本时标unknown，不宣称可复现模型快照。

## 三层确定性
1. 固定审计输入→代码计算可以测试完全相同。
2. 固定brief与证据→同一模型重复运行用于检测判断波动；不能证明正确。
3. 以后更换底模→可选进行顺序回放，比较事实忠实度、创新差量和选题层级；不要求当前同时拥有多个模型。
真实查新需要当前文献，不能为了题目相似永久使用过期证据。固定的是流程，不是固定答案。

## 轻量执行，不牺牲证据
14阶段是固定逻辑边界，不要求14次独立模型API调用；宿主可在同一次交互内完成相邻阶段，但保留各自产物。
种子只需短结构化条目；仅对最多10个正式候选深审。复用来源、查询和术语缓存；哈希、计算和格式交给代码。
不输出长角色辩论、不每一步全量重读、不无限修复。速度或费用改善尚未实测，不能宣传倍数。

## execution记录
```json
{
  "mode": "single_model_sequential",
  "generator_model_id": "actual-host-model-id",
  "reviewer_model_id": "actual-host-model-id",
  "review_type": "same_model_self_audit",
  "independent_review": false,
  "context_mode": "same_context",
  "exposed_to_previous_scores": true
}
```
此对象由宿主依据真实运行填写。ID相同的声明校验无法证明平台底层执行情况；不伪造调用日志。

## 首轮与后续证据界线
首轮问题种子无需假装已获文献支持，所有预设均为未证。必要术语可以先查。
正式候选必须说明可靠前提和要验证的未知关系；不能要求创新假说已经被文献直接证实。
新上下文可隐藏第一轮的具体题目，但用户已提供的目标与约束必须保留；不得丢失关键反证。

## 不可更改的输出原则
五题是五个不同的科学问题，不是五段措辞。每个题必须对最接近工作解释知识增量。
排序差异可由证据更新或真实科学判断不同产生；不以标题重合率替代选题质量。
未确认的创新性显示未知/条件性，不以“模型没想到过”或“搜不到”当原创证明。

## v2.0正文规则优先
单模型和审查限制保留在审计档案；默认正文不展示模型身份、打分与敏感性。实际证据和资源不足必须用学术语句说明。正文按writing-standard输出导师论证稿，不假称人工独立验证。
