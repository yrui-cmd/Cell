# 最终报告模板

下方是版式合同，不要把尖括号和说明原样交付。正式报告由report_sections四段生成，段内数字引文与最后的参考文献对应。编号表示顺序，不是评分名次。

```text
【研究方向】选题论证
资料检索截至：【实际日期】。
【仅在必要时用一句说明资料更新或获取限制。】

一、【具体题目】
研究依据：【最接近文献的对象、结果边界与未解问题。】[1,2]
拟研究内容：【要回答的具体问题；相对既有研究新增的检验或认识。】
研究方案：【首项验证、核心比较与主要测量；后续研究仅写必需环节。】
可行性与限制：【已确认条件、尚需条件、主要替代解释或不可判定情况。】

二、【具体题目】
【同样四段，不重复泛泛背景。】

三、【具体题目】
【同样四段。】

四、【具体题目】
【同样四段。】

五、【具体题目】
【同样四段。】

【必要时：五题共同依赖的未证前提或资料限制，一短段。】

参考文献
[1] 【已核验的作者信息，如无则省略】. 【题名】. 【来源、年份；仅填已核验字段】. 【DOI或实际链接】
[2] ……
```

每题四段合计约220–350字；不硬截断研究限制。没有用户要求不加总表、首选、五维评分、创新等级、审查状态或重复方法流程。
研究条件未落实时直接写“该选题以取得××为前提，目前尚未确认”；只有部分资料时写“现有资料尚不足以判断××”，不要把unknown翻译成“已具备”或“原创性低”。
主文只用实际入选的五个问题及其来源。默认保留现有排序，但不宣称学术高低已确定。使用scripts/render_report.py生成的2.0报告为本模板；1.1仅供旧版本回放，不用于新任务。
