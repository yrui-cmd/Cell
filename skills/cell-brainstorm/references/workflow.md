# 固定工作流 v2.0

## 显示与内部阶段
只在第一次实际进入对外步骤时发送 `第N步`，不把本文件过程打印给用户。逻辑阶段不等于API调用次数。相邻子阶段可同一次调用完成，但各自产物和校验不能省。保持同一个model_id；返工只在受影响候选，最多两轮。

| 可见步骤 | 内部编号 | 文件或记录 |
|---|---|---|
| 第1步 | S00–S02 | run_manifest、brief、constraints、concept_map、seeds、exposure |
| 第2步 | S03–S07 | query_plan、search_log、source_registry、evidence、landscape、postcheck_seeds、revisions、shortlist |
| 第3步 | S08–S09 | nearest_work、novelty_audit、critique、revision_rechecks |
| 第4步 | S10.paths | execution_paths、constraint_ladder、dependencies |
| 第5步 | S10.validation | minimum_validation、prediction_matrix、premortem |
| 第6步 | S11–S13 | audit_bundle、final_report、sensitivity、freshness、snapshot |

原S10拆成两个可见步骤，内部仍属于一个设计阶段。新版本输入必用2.0 schema。小型宿主可把同阶段记录合并为JSON文件，保留字段及来源定位；只存可核对结果，不存私有思维链。

## 第1步｜界定范围与首轮候选
输入：原始请求、用户可用资料、宿主工具。
1. S00检查检索、阅读、文件与代码能力；记录live/replay/offline及真实时间。确认隐私边界，锁定实际模型标识；查不到具体部署版本标unknown，不捏造。缺联网不谎称实时。
2. S01提取对象、情境、结局、研究类型、价值目标与排除项；保留原话。将资源写入constraints：confirmed/path_identified/assumed/unknown/unavailable，给依据、是否可协商。未确认不是没有，也不是已有。缺非关键字段继续；根本没有主题才问一句。
3. S02做必要术语消歧；未知词先查。研究类型见research-types，领域来源路线见config/domain-profiles.json。建立同义词/旧名/邻近词，邻近词不视为同义词。
4. 围绕统一任务范围提出目标12个未验证种子：竞争/反向解释、时间与边界、尺度互作、测量识别、结构类比与假设反转、约束权衡与关键验证；每操作目标2个，不凑数。种子必须有问题、类型、未证前提、回答标准和可观察差异或知识增量，暂不评分。已读文献/参考题记exposure，不能声称真正盲想。
通过：范围清楚而非预定答案，多个不同问题原文锁定。严重脱题删除；合理未证关系保留。

## 第2步｜研究地图、二轮发想与改造
输入：brief、种子、固定检索族。
1. S03冻结六类宽检索计划及关键词、来源、日期。保留不依赖初轮种子的宽领域搜索，不能只找自己观点的支持。
2. S04真实检索、筛选、去重；论文和预印本关联study_id；读取最相近原始研究、必要图表和方法。保存工具回执或实际返回；失败不是零结果，摘要不是全文。日志详见source-protocol。
3. S05逐条记录known/inference/hypothesis：对象、设计、条件、比较、结果方向、局限、source_id及定位。来源只支持本来支持的范围；元数据不验证语义。引用相互重复的数据不是独立重复。
4. S06建立已解决、部分解决、冲突、瓶颈、不可核验五栏；每个gap给最接近工作、具体边界、重要性以及为什么现在值得检验。当前环境包括公开知识、在研竞争、技术基线和用户资源。
5. S07在新证据后重新发想目标12条，再与初轮合并最多24；真新题、修订、同题与淘汰分别记录，不必凑满。使用enhancement的假设账本、结构类比与问题变换，不能只把技术或名词换一下。
6. 对有依据前提且问题重要的薄弱候选，先试一次最强合理版本、知识增量增强、实现负担下降；关键推断改变建立新版，进入S08重查。已解决同题无其他贡献、错误前提和不可化解禁区不可包装保留。
7. 根据统一rubric、范围和明显重复做临时短名单最多10；初轮无评分不等于正式候选阶段不能按既定规则排序。临时得分不作为创新已验证的结论。
通过：至少形成有来源的边界和正式问题；资料不足记录缺口而非想象填补。

## 第3步｜逐题主动查重、反证与时效
输入：短名单、原子证据与候选版本。
1. S08执行实质同题、同义词、去限定、邻近关系、反证、最新/在研六类查询。最近是科学问题最接近，不只是年份最近或影响因子最高。比较实际找到的2–5篇，不足如实记。
2. 对每个最近工作写对象/条件、设计、支持或提出内容、没有回答的范围、定位、重叠度。只读摘要不能断定正文没做某实验；未命中不证明空白。
3. 给具体创新差量、价值、N等级及置信度；新假说无需先被证明，但其前提与研究边界必须核对。
4. S09同模型自查：最强替代解释、前提误读、单位/因果/阶段偷换、测量伪象、实际反证、最不利合理解读、修正与残余未知。same_context如实记已暴露；新上下文仍不是独立专家。
5. 实质改题增加version、保存父版本，重查后才设置last_novelty_checked_version。纯文案修订不声称创新增加。局部修复最多两轮；不足标conditional或删除。
通过：每题有可追溯最近工作与差量，负面证据不被抹掉。无方法的“相关”不能当因果，合理描述性课题则用其自己的回答标准。

## 第4步｜证据链与执行路径
输入：查新后的候选及constraints。
1. 从核心结论倒推必需证据、有效测量、比较/对照、精度与推断单位，不从会做的技术列表拼方案。
2. 每题定义P0最小验证、P1核心研究、P2可选扩展；P0和P1不得空缺。P2可not_assessed并说明。按路径记录不同状态，不以P0容易给全题高可行性。
3. 现实条件current；仅放宽一个明确可协商条件relaxed（仍为反事实，不当作已获资源）；再收紧一个条件tightened。安全/伦理/授权和用户硬禁止项不可放宽；无可协商项说明not_applicable。
4. 同一路径dependencies为AND，不同routes为OR。confirmed需实际依据；path_identified还没落实；unknown需核实；unavailable且无可保留结论的替代才阻断。备选路径删除决定性对照则claim_preserved=false，不当作等价。
5. 核对已有数据的变量、采样单位、时间点、分组、质量、授权；用户资源的来源是用户确认/真实资料，不能用别人的论文替代。必要审批未取得标条件性而不是已批准，研究规划不等于执行。
通过：核心结论和证据匹配，必需资源和允许结论可追溯。改变主张回第3步内部复查；不重报进度。

## 第5步｜最小验证与决策规则
输入：P0/P1、最强替代解释或研究类型对应标准。
1. 列关键未知，按能否改变继续/调整/停止决策选择优先检查，不为造图先做便利分析。不编造信息增益、成功率、工期、价格或样本量。
2. 分开可行性检查、科学判别、测量验证与证明任务，填minimum_validation.purpose。planned为默认；只有有实际执行记录和结果才为executed，列execution_evidence_refs。
3. 在同一测试/相同条件下列主预测、比较预测、混合或不可判定情形、区分观测和必要质量检查。方法题用公平基线，描述题用覆盖/误差/精度，理论题用命题假设与反例，不强制二元机制。
4. 固定填写继续、调整、停止、不可判定。操作未生效、测量失效、精度不足和解释仍重合不算否定假说。不显著不自动无效；结果相反先排除质量问题。
5. 指出精度方案需要的效应、方差、独立单位和相关结构；未知写待估参数。最小试验并非必然低样本量，低投入不得破坏回答能力。
6. 失败预演覆盖最影响解释力的理论/测量/执行卡点，写早期核查、缓解、剩余风险。负结果知识价值仅在质量与精度允许时成立。
通过：可以据方案解释不同结果；未执行不编造结果，最小试验不是附加实验权限。

## 第6步｜门禁、五题、复查与交付
输入：schema2.0完整audit_bundle及实际工具记录。
1. S11先原有八项底线和检查，再三道科学门：knowledge_gain、answerability、feasibility。pass/conditional/fail，任一fail不能靠总分抵消；未知不强行作fail或pass。只有方案的假说尚未验证不构成自动失败。
2. 保留N/V/F/T/E与原固定权重。F以P1而非P0为准；T按研究类型评可回答性。代码固定门禁、排序、同分、去重，不能验证科学语义。新字段校验防未查新版本、资源矛盾、假执行和无质量解释的结果分支。
3. question_key按对象/条件/核心未知/回答标准去重，同gap上限2；不是按标题或技术相异填五题。检查五题共同依赖的未证前提，共享资源不扣分。先合格、后条件性、不足留空位。
4. 固定权重敏感性仅诊断。decision_uncertainties记录哪条未知会改判断、条件分支和下一项核验；不把有利分支当事实。
5. S12对暂选五题做最终最新同题/关键反证/版本状态核查。发现关键新证据回S08及受影响下游；最多两轮/预算内。默认报告前24小时内实际查新。无实时能力不称最新；冻结实际读到内容而不是声称保存全网。
6. S13本地渲染或按模板表达，五题和来源不能在写作时加新事实；进度简洁不限制最终必要解释。默认正文每题约220–350汉字（不含来源，软目标），依writing-standard写为四段学术短文。评分和审计留档；资源未知与关键限制不能为长度删除。
7. 保存完整候选、审计与日志，但不在聊天打印。最终报告含题名、资料截至日、必要覆盖局限、五题及数字引文与参考文献。共同前提风险仅在影响备选价值时以一句实质说明保留。不展示模型、门禁、权重、置信度或阶段名；回放/离线限制用“依据截至某日资料，未完成当日复核”等普通学术语言说明。
完成：五个独立候选或明确缺额，结果可审计；没有执行的步骤和科研质量验证如实说明。
