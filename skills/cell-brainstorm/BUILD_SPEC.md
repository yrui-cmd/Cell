# 交付范围与维护

v2.0.0为最终六步、单模型、简洁进度及导师论证稿版本。包含真实文件化Skill、规则、schema、来源与自查协议、候选增强、本地校验/排版/快照/进度脚本及测试；不是待填充空项目。

实际文献检索和模型推理由宿主提供。本包没有独立LLM客户端、联网爬虫或自动实验/论文投稿能力，也不声称用本地PASS证明科研正确性。

新任务用schema2.0。1.1仅回放兼容，正式输出不得沿用旧版评分表。新增模型只在下一个任务开始时替换，不在一次任务中启动第二模型。维护者须版本化规则、重新运行tests，不能临场调权重让某题入选。

cell-brainstorm保留原名字，便于调用；安装须保留整个目录并备份已有版本。源码和运行数据分离，输出只有在真实创建后可发下载链接。库上传、共享、外发秘密资料或系统安装不属于本次生成授权。

验证报告在tests/validation_report.json：本地单元与CLI检查、打包完整性分别记录。真实文献语义、选题质量与不同模型稳定性属于未完成实证验证，不用合成用例冒充。
