# 配套材料与事实边界

以下是按需处理规则，不是默认交付清单。只有期刊明确要求、条件已触发或作者明确请求的项目才执行；可选材料默认不生成。

## Cover letter

从最终主稿抽取题名、文章类型、问题、1–2 条有证据的主要发现、具体研究增量和读者相关性。通常使用短段落；实际长度服从本刊要求。不复制整篇摘要，不使用“颠覆性”“完美适合”“全球首次”等无证据宣传。编辑姓名未核实时用 Dear Editor。

原创性、非重复投稿、全部作者同意、利益冲突等声明，只有作者已经提供可信信息才能写成事实。没有确认时只记入内部待补项，最终一句话告知，而不是默认声明为真；本刊必需内容尚缺时封面信仍为待完成稿。已有预印本、关联稿件、会议摘要、专利或注册信息，按实际规则披露，不把预印本自动判为重复发表。

## Title page 与作者信息

只使用作者给定的姓名、顺序、单位、共同一作/通讯标记、ORCID、邮箱及联系方式。核对姓名拼写与单位序号。不得按作者排序猜测贡献、资历或通信责任。ORCID 可检格式但不能把格式正确当身份已验证。

## 声明

| 项目 | 有证据时处理 | 无证据时处理 |
|---|---|---|
| Ethics / Consent | 逐字核对机构、批准号、知情同意与适用范围 | 缺失项，不写“已获批”“获豁免”或“不适用” |
| Funding | 保留机构、项目号和资助角色 | 不写“无资助” |
| Conflicts of interest | 沿用真实作者披露，按期刊表述 | 不写“无利益冲突” |
| Author contributions | 按作者确认内容映射要求的贡献分类 | 不按一作/通讯位置自动分工 |
| Data / Code availability | 核对真实存储库、登录号、访问条件、访问令牌用途 | 不伪造 DOI、公开链接或“合理请求可得”承诺 |
| Trial / Study registration | 沿用真实注册号、日期、平台 | 不补造、不倒签 |
| AI use | 如实记录工具名称、实际已知版本、用途与位置，按该刊要求披露 | 不猜模型版本、不使用“未使用 AI”掩盖已知使用 |
| Permission / Consent to publish | 核对已有许可、范围及所用素材 | 不伪造授权，不默认有版权 |

数据公开、限制访问或暂不可得的表述需与伦理、数据使用协议及期刊政策相容。不能因数据来自公共库就自动宣布二次分析免伦理。不得代各作者签署官方利益冲突表或许可协议。

## Highlights / 图形摘要 / 补充材料

Highlights 的条数与字符上限从本刊提取，并以最终文案实际计数。不得给主稿未支持的新结论。

图形摘要先复用作者现有、允许使用的版本；需新作时从锁定内容出发。绘图能力是否可用、生成式图像是否被该刊允许必须查清。不能用生成图修复或替代原始实验照片、病理图、显微图或条带。

补充材料保持 S 编号、主文引用和图表标题一致。对数据表保留可读结构、单位、变量说明，不改变数据值。需要原始条带、source data 或数据存储证明时，只用真正已提供/存在的材料，不从图片倒造“原始数据”。

## Reporting checklist

先识别研究设计，再从官方指南/开发组织取得合适版本与扩展；如随机试验、观察性研究、系统综述、预测模型、诊断研究、动物研究及领域专门规范。混合设计可对应多个适用部分，但不把所有清单一律附上。

填写顺序：确定适用性 → 检索稿件真实位置 → 记录页码/行号/补充位置 → 未报告项列为缺口 → 最终排版后更新定位。不用聊天中的计划、常见惯例或推断替代已经完成的实验信息。

PDF 表单如采用 XFA/专用脚本而当前工具不能可靠填充，报告格式限制；可在内部准备对应答案并将无法填表列为阻断项，不默认另造答案附件，不得称为已经填好的官方表。

## 推荐/回避审稿人

仅在本刊要求且适用，或作者明确要求并且本刊接受时处理。用公开机构主页和近年论文核对研究匹配、姓名、机构与官方邮箱；不能从姓名猜邮箱。遵循本刊关于同单位、近期合作者、师生等冲突的具体标准，不编造无冲突保证。

姓名相同或关系不明则保留待核对。不得联系候选人、创建邮箱、冒充审稿人或设计绕过编辑审核的名单。回避理由须真实、简短且与冲突相关。

## 投稿系统字段

期刊要求的题名、摘要、关键词、作者、单位、基金、声明、文件类型及分类，读取真实规则后留在内部待填字段；作者信息顺序必须与最终稿相同。不默认生成字段说明附件，也不把内部字段当作已经填入系统。仅当作者明确索要时输出对应可复制文本。没有读取真实系统时，不能声称系统字段已经全部核验。

资料上传可能将未发表研究提供给外部服务；必须有用户授权和可用工具。任何签名、费用、版权许可和最终提交均不能从“准备投稿材料”这句话推定授权。
