# 正式审稿回复写作规范

本规范用于第二阶段正式回复，也指导第一阶段的问题追踪。目标期刊模板、编辑决定信中的明确要求优先于本文件；适配格式时不得放宽真实性、完整性和可追溯性门槛。

## 优先级与问题追踪

按以下顺序处理：编辑决定与期刊硬性要求、编辑逐项意见、Reviewer 1、Reviewer 2 及后续审稿人。编辑要求与审稿意见冲突时不要自行折中，保留冲突并请求作者决定或按决定信中的明确优先级执行。

每个原子问题除处理路线外，登记：

- `category`：clarification、methods、experiment、analysis、statistics、figure、table、references、reporting、formatting、data_or_code、scope_or_interpretation；
- `severity`：high、medium、low，表示对可信回复和修订稿的影响，不代表审稿人身份或语气；
- `status`：ready、open、resolved；
- 稳定 ID、父意见、所需证据、实际动作和最终定位。

高严重度不自动等于必须新增实验；先判断问题是否能由已有证据、结论收窄、方法澄清或有依据的不同意解决。

## 回复策略

第二阶段为每条父意见选择一个主要 `response_mode`：

| 模式 | 使用条件 | 必须说明 |
| --- | --- | --- |
| agree_and_change | 认可问题且已实际修改/分析/实验 | 直接答案、具体动作、结果与位置 |
| partial_agreement | 认可一部分并保留一部分 | 哪部分修改、哪部分保留及其科学边界 |
| clarification | 现有材料足够，主要消除误解 | 直接答案、已有证据和是否无需改稿 |
| reasoned_disagreement | 请求不适用或会造成错误推断 | 关切为何合理、不同意的证据、必要的范围澄清 |
| unable_with_alternative | 原请求无法科学或数据上完成，但已有诚实替代处理 | 不能完成的实质原因、替代分析/限制、剩余风险 |

不能把时间、经费或方便性作为无法完成的主要理由。不能把部分采纳写成完全接受，也不能把“审稿人误解了”当作论证；先检查原稿是否表达不清。

## 单条正式回复结构

按以下顺序生成 Word 区块：

1. `Comment`：逐字保留原始意见；
2. `Response`：先直接回答，再解释依据；
3. `Changes made`：说明已经发生的具体修改，或说明为何无需修改；
4. `Revised manuscript text`：仅在有帮助或期刊要求时提供，与当前修订稿逐字一致；
5. `Locations`：使用当前稿真实章节、页/行、公式、图、表或补充材料位置。

回复正文通常按“确认核心关切 → 明确答案/立场 → 数据、方法或文献依据 → 已落实修改与位置”展开。感谢要简洁，不用重复套话代替答案。一个父意见含多个子问题时，在同一正式回复中逐项覆盖；重复意见可以交叉引用，但当前审稿人的问题仍须得到直接回答。

## 主要修改摘要

开场后列出精简的 `Summary of principal revisions`。只包含真实完成、会实质影响论文理解或可信度的修改；不把一般语言润色、颜色标注和内部流程包装成主要贡献。摘要中的每项内容必须能在逐点回复与当前修订稿中找到对应证据。

## 真实性与一致性

严禁虚构实验、分析、样本量、重复次数、统计量、显著性、引文、DOI、仓库记录、页行号、图表号、编辑要求或身份。第一阶段可以使用明确占位符；只要仍有占位符、未核验数字、待完成动作或缺关键作者决定，就不能标记 `ready_to_submit`。

提交前交叉检查回复信、清稿、标色稿、图表和补充材料：

- 方法名、数据集、参数、样本单位和数量一致；
- 表格数字与正文、图和补充材料一致；
- 同一异常结果的解释一致；
- 新增引用确实进入参考文献；
- 章节、公式、图表和附录真实存在；
- 清稿与标色稿科学内容一致，仅修订呈现不同；
- 回复没有越过实际证据边界。

## 完成状态

- `draft_with_placeholders`：结构已建立，但仍有明确占位符或待定位内容；
- `needs_author_input`：缺作者事实、结果、文件或决定；
- `blocked`：存在研究诚信、合规、申诉或核心证据问题，不能按普通回复完成；
- `ready_to_submit`：全部意见已覆盖，修改落实，事实、位置、格式和最终文件均已核验。

状态描述事实，不是手工放行开关。`ready_to_submit` 与任何 open issue 不兼容，第二阶段生成器只接受该状态。
