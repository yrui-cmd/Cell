# 审稿意见中英文对照归档规范

## 目的与范围

本规范用于把 decision letter 中编辑和审稿人的全部父意见整理成可追溯的 Markdown。它是后续问题拆分、Figure 归类和正式回复的共同底稿，不是对审稿意见的摘要，也不包含作者回复。

必须纳入编辑要求、总体评价、编号与未编号意见、补充材料要求、数据/代码/统计/方法/图表/文字修改要求。不得因内容重复、不利、看似简单或与 Figure 无关而省略。

## 语言方向

- 英文原文：译为中文。
- 中文原文：译为英文。
- 中英混合或其他语言：保留原文，并明确选择英文或中文作为译入语言；不得用 `mixed` 逃避翻译。
- 原文和译文分栏式连续呈现，不把译文写进原文引用块，不让译文替代原文。

## 忠实度锁定项

翻译应传达原意，不增添解释、承诺、反驳或作者行动。逐句复核以下内容：

1. 数字、正负号、百分比、范围、单位、样本量、P 值、置信区间和效应量；
2. Figure、panel、Table、Supplementary、Section、page/line 等标签和编号；
3. 文献序号、作者名、年份、DOI、URL、数据库号、基因/蛋白/模型/算法名称；
4. 否定、条件、比较对象、因果关系以及 must/should/may 等语气强度；
5. 审稿人的疑问、批评和不确定性，不能被弱化成一般建议，也不能被强化成编辑决定。

术语没有可靠对应译法时保留英文术语并给出简洁中文说明；存在真实歧义时忠实保留歧义，可在 `translation_note` 中说明，不得擅自替审稿人消歧。只有完成原文—译文逐句核对后，才记录 `translation_checked: true`。

## Markdown 固定结构

按“编辑在前、各 reviewer 依来源顺序”的结构输出。每条父意见使用以下信息：

```markdown
## Reviewer 1

### Comment 2（R1-C2）

- 来源位置：Reviewer 1, Comment 2

#### 英文原文

> 原文逐字转录

#### 中文翻译

> 忠实译文
```

无原编号时只显示稳定内部 ID，不伪造 `Comment 1`。多段原文按原段落保留；Markdown 特殊字符应被安全呈现，不能改变肉眼可见的内容。原始来源位置必须足以回到 decision letter、附件、邮件或经核对的转录本。

## 完成检查

- 父意见数量等于来源统计数量，reviewer 分项数量一致；
- 每条意见都有唯一 ID、原始顺序、来源定位、完整原文、反向语言译文；
- 原文与来源逐字核对，允许的只有读取造成的空白归一化；
- 译文已逐句核对全部忠实度锁定项；
- Markdown 不包含拟回复、解决方案或虚构的稿件修改；
- 来源缺页、截断或不可读时明确记录缺口，不宣称完整归档。
