# 中英文科研论文深度润色

让修改后的中文或英文仍像作者本人写的，只是科学含义更准确、逻辑更清楚、证据边界更严密、语言更符合正式期刊表达。默认保持原稿语言；只有用户明确要求翻译时才改变语言。修改优先级为：科学准确性、论证逻辑、证据匹配、信息完整性、段落结构、语言准确性、流畅度、文风美化。

用户未另行指定时，默认以短句和中等长度句为主，一个句子尽量承载一个核心判断。只在多层从句、插入语或多重逻辑妨碍阅读时拆句，不按固定字数切句，也不把全文改成碎短句。逐句核对语法，并按动作时间和句子功能选择时态；用户在当前任务提出的新风格要求优先。

## 使用边界

先锁定用户要求的范围，不把局部润色升级为全文重写。

- `language_edit`：修改语法、用词、简洁性和衔接；发现严重科学或逻辑风险时另行指出。
- `logic_edit`：在指定范围内修复论证顺序、证据链、替代解释和结论强度。
- `audit`：只报告问题、风险和建议，不直接改原文。
- `translation_edit`：把作者已有中文研究内容忠实转写为英文，不逐字翻译，也不增加原意之外的信息。
- `comprehensive_edit`：只有用户明确要求全面润色时，才同时处理结构、逻辑、证据和语言。

缺少可供润色或忠实转写的原文、研究事实与必要上下文时，不从常识补写论文内容。从零界定综述问题、扩展证据并写完整综述使用 `cell-review`；修改已有综述稿的英文、论证、跨研究比较和结构仍使用本 Skill。审稿回复使用 `cell-reviewer-response`；定稿后的期刊格式和投稿材料使用 `cell-submission`。

## 按需读取

- 所有实际润色都读取 [科学保真与结论强度](references/scientific-integrity.md)。
- 写作与润色默认读取 [发布会原则](references/publication-principle.md)，在第2—3步安排主线与证据职责，第4步清理无信息自贬，第6步回核；局部语言修改只在已授权范围内执行。
- 英文稿读取 [英文学术表达](references/english-editing.md) 和 [英文学术文本自然化流程](references/humanization-pass.md)。
- 中文稿读取 [中文学术润色与内置人话流程](references/chinese-editing.md)。
- 第4步中，所有语言读取内置的 [anti-defensive-writing](references/vendor/anti-defensive-writing/RULES.md)；中文稿随后读取内置的 [lieflat-less-ai-tone](references/vendor/lieflat-less-ai-tone/RULES.md)。主 Skill 的科学保真、任务范围和作者明确偏好优先于内置规则。
- 涉及逻辑、Discussion、全面润色或证据审查时，读取 [论证与证据链](references/argument-and-evidence.md)。
- 涉及补引、替换引用或整篇重建参考文献时，读取 [引用构成检查](references/reference-composition.md)，按研究问题记录并执行适用的引用证据策略。
- 修改已有综述的段落论证与收束时，读取 [有证据的正向有用结论](references/constructive-conclusions.md)，在第2—3步处理、第6步回核；局部润色仅评价已读取的授权范围，不外推全文比例。
- 润色完整章节或全文时，读取 [分章节标准](references/section-specific-editing.md)。
- 用户提供历史改稿、明确偏好或要求全文保持同一风格时，读取 [作者风格校准](references/author-style-calibration.md)。

## 不可改变的事实

未经明确证据，不改变数据、数值、单位、样本和组别身份、研究阶段、实验条件、方法、统计结果、效应方向、图表编号、引文身份和专业实体名称。不能把相关改成因果，把可能性改成确定性，把局部结果推广为普遍规律，或补造数据、机制、作者观点和文献。

原文存在歧义时使用最保守且最接近原意的英文，并标出会影响科学判断的未决点。语言更自然不是提升结论强度的理由。

## 润色流程

### 1. 锁定输入和范围

读取指定原文及完成判断所需的相邻段落、图表、引文或作者说明。识别原稿语言和中英混合区域，默认以原稿语言交付；中文润色不得静默转成英文。明确论文部分、润色模式、允许调整范围和必须保留的术语。文件任务保留原件，在副本上工作；不能只根据摘要或文件名判断全文。

涉及新增或替换引用时，新增且最终保留的去重文献按已记录的证据策略检查；仅experimental75模式要求实验性研究至少75%，理论/计算/观察主题和正式综述按对应设计或预定标准评价。整篇重建参考文献时按全文实际引用统计。单纯语言润色保留作者原有引用，指出需要追溯原始研究的具体位置；不因比例规则自行扩大成补引任务。统计范围及分类见 `references/reference-composition.md`。

### 2. 先理解再修改

先按 [发布会原则](references/publication-principle.md) 从已有证据中确定最强贡献和最硬结果，在内部建立“贡献—证据—段落/实验/图表职责”的对应关系。逻辑或全面润色按该主线组织叙事，摘要与引言突出问题、缺口、思路及关键发现，结论收束到同一贡献。

识别文本要回答的科学问题、核心判断、直接观察、解释、进一步推论和重要判断的证据来源。对逻辑润色、全面润色、Discussion 或已有综述，先记录整篇/本节的中心判断，并给每个段落或小节标注功能（定义、证据、比较、解释、边界、过渡或结论）；不得为“优化逻辑”发明作者没有提出的新贡献。正文直接推进论点，按理解需要展开技术细节；方法选择自然衔接已考虑的可能性、取舍依据和当前设定。从已有正文与数据提炼主要发现、最有力依据及其意义，供摘要改写使用。逐段检查新增信息，标出重复铺垫、文献堆砌、缺少解释的结果罗列和无依据的泛化结论；明确读者能获得的具体理解。先处理逻辑与证据层级，再调整语言；不能用顺滑语言掩盖论证缺口。

### 3. 最小必要修改

按论证职责删去过程流水账和重复实验描述；保留必要对照、关键反证和影响核心判断的结果。比较维度依据真实研究目标选取，目标差异与权衡解释须能回到设计和数据，不因结果不占优而改写既有主要终点或比较事实。

准确、清楚的原句可以保留。优先删除重复、修正术语和指代、调整必要句序、补清真实逻辑关系、降低无依据的强断言，并去除空洞评价和机械套话。删除前问：移除此处是否会损失必要事实、比较、解释、边界或读者导航？多处限制只有在对象和影响相同时才合并；研究特异限制、直接约束某一结论的限制以及图表独立理解所需信息继续就地保留。长句妨碍理解时按核心判断拆分，再补清句间关系；不要为了显示修改量重写每句话。

摘要在核对正文后定稿，突出实际发现及明确结论，压缩章节介绍和空泛背景。正文在授权范围与现有证据内补清结果的含义、研究差异及成立条件；删去重复评价和无信息增量的句子，必要解释写完整，不为缩短篇幅让读者猜。缺少依据的判断标为待补证据，不由语言润色补造。

已有综述的段落收束执行正向有用结论至少60%、否定或局限主导结论约40%以内的目标。先从原稿与已核验证据提炼具体认识、适用条件或选择依据，再合并重复的泛化否定；必要限定就地保留。空泛赞美、把缺证据改成潜力、升级因果或改写负结果均不能用于凑比例。具体分类与证据不足时的处理见 [有证据的正向有用结论](references/constructive-conclusions.md)。

### 4. 去除模板腔并恢复作者节奏

只有第2—3步的科学含义、论证和必要结构已经稳定后，才运行本步的内置规则。

按发布会原则检查优势是否已由正文具体说明，并将空泛自贬改成准确的结果、条件和实际意义；“仅”等词保留有科学含义的限定用法。

第一遍对所有语言应用内置 [anti-defensive-writing](references/vendor/anti-defensive-writing/RULES.md)：识别不必要免责声明、真实范围条件、方法限制、证据限定和有用概念区分；删除没有增加证据、范围、逻辑或读者指引的防御性说明，用正面范围替代习惯性否定表述。真实不确定性、不利结果以及影响有效性、解释、适用范围、伦理、安全或复现的限制必须保留，不能为了语气有力而升级结论。

第二遍按语言处理。英文稿按 [自然化流程](references/humanization-pass.md) 检查聊天残留、空泛铺垫、意义膨胀、虚构对立、无来源权威、通用结尾、重复句式和机械节奏。中文稿按 [中文学术润色与内置人话流程](references/chinese-editing.md) 调用内置 [lieflat-less-ai-tone](references/vendor/lieflat-less-ai-tone/RULES.md)，只修改明确命中的白名单问题；未命中内容保持不变，不改变标题层级、段落任务、事实、引用和结论强度。作者已确认的语言习惯与体裁规范优先。

避免迂回立论和防御式表达，少用 `not X but Y`、`rather than`、`since`、`however`、`therefore`、`not only but also` 及对应的中文模板结构；不要为了回避这些结构增加无必要解释。单个词、被动语态、`we`、必要限定词、三项并列或某种标点都不是自动改写理由。

英文完整文件或较长英文章节应在可提取为 UTF-8 文本时运行：

```bash
python scripts/academic_prose_lint.py path/to/manuscript.txt
```

结果是人工复核线索，不是 AI 作者判定或验收分数。没有实质问题时保持原文，不通过反复改写、故意语病、随机标点或虚构个人经历制造所谓“人类感”。

### 5. 继承作者选择

同一任务中持续继承作者已确认的术语、结论强度、句长偏好、禁用表达和不修改区域。注重措辞与行文节奏，减少过度解析和长难句，拆解妨碍理解的长句，并保持长短句配合。需要跨章节复用时，从 [示例 profile](assets/author-style-profile.example.json) 建立任务级文件并运行：

```bash
python scripts/check_author_profile.py path/to/author-style-profile.json
```

profile 是显式任务资料，不代表跨会话自动记忆。用户的新明确要求覆盖旧偏好，但不能覆盖科学事实。

### 6. 回核最终文本

回核发布会主线：核心优势是否有相称证据，摘要、引言和结论是否围绕同一贡献，比较对象与口径是否清楚，权衡解释是否有依据，以及删减后必要对照、主要指标和关键不利结果是否完整。

对照原文、图表和可用证据复核数字、比较对象、方向、限定词、术语、时态、图号和引文。英文逐句检查主谓一致、句子完整性、冠词、单复数、介词、修饰关系和指代；中文检查标点、指代、语序、术语译名、中英文混排和长句理解负担。拆句或重组后再次检查语法、时态与逻辑衔接。确认删减没有移除必要条件或已有的正面综合判断，重组没有改变时间、因果关系或研究间可比性，语言转换没有增加新含义。以首次阅读者视角回读，核对论点推进、方法衔接和阅读负担。主文、表格和图注职责分开：主文推进判断，表格支持系统比较，图注保证图形在合理范围内独立可读；不能通过删掉“重复”信息使其中任一部分失去作用。

增加信息价值回核：摘要是否给出正文支持的答案，空话是否减少，关键解释是否清楚，读者能否更容易理解并使用这些信息。只有目录式摘要或无新增认识的正文时，返回第2—3步修改。补引任务按新增且最终保留的文献、全文重建任务按全文执行引用构成检查；新增为零时标记不适用，不报告为100%。

已有综述按实际编辑范围登记段落收束的P/L/U分类及比例，核查各正向判断的原稿或来源依据。低于60%时复查可改进的表达；证据确实不支持时保留判断并记录具体原因，不伪报达标。局部修改不额外扩写无关段落，也不据局部比例声称全文达标。

完整文件或较长章节应保存修改前后两个文本版本并运行：

```bash
python scripts/check_manuscript_preservation.py before.txt after.txt
```

该脚本只比较部分可机械保护的数值、单位、交叉引用、引文、公式、链接和直接引语。无论结果是否通过，仍须人工复核否定、归因、因果、不确定性、比较方向和研究范围。

## 输出

- 短文本：默认提供与原稿语言一致的完整润色稿，再简要说明会影响理解的关键修改；用户要求只给修改稿时不附解释。
- 审核任务：区分确定问题与待确认风险，给出原文定位、原因和最小修复方案。
- 文档任务：沿用用户指定或原文件格式；只有用户要求时才生成修订痕迹、逐条对照或额外报告。
- 证据不足：指出需要补证据或降低强度的位置，不偷偷插入看似合理的引用。

## 完成条件

- 修改范围与用户要求一致，没有擅自扩写、从零续写或整章替换。
- 事实、数字、实体、图表和引文与可用材料一致。
- 观察、解释和推论层级清楚，结论强度由证据决定。
- 核心判断和章节功能在结构调整前后保持可追溯；没有把重新排序冒充新贡献。
- 重复限制只在对象和影响相同时合并，已有的正面判断没有因统一弱化而丢失。
- 段落围绕明确问题展开，术语与缩写一致；摘要有正文支持的主要结论，核心段落提供具体信息或理解。
- 涉及补引或整篇重建参考文献时，已按相应范围执行已记录的证据策略；experimental75模式保留75%要求，其他模式核对对应原始证据。未达相应要求如实说明，不宣称补引任务完成。
- 中文或英文准确、直接、克制且自然，没有为“学术感”堆叠抽象词、套话或宣传式意义。
- 模板化模式已经结合上下文和作者样本复核；没有把模式命中误报成作者身份判断，也没有为了规避检测而制造噪声。
- 已检查长难句的阅读负担，并在拆句后复核语法、时态和逻辑衔接；没有因简化句式损失科学含义。
- 最终版本已经回读；未取得的证据和未完成的检查被如实说明。
