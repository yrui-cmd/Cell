# 论证与证据链

## 段落模型

先判断段落回答的问题，再识别每句功能。常见有效结构包括：

- 中心判断 → 直接证据 → 解释 → 辅助或反例证据 → 有边界的小结。
- 提出问题 → 比较解释 A/B → 给出区分证据 → 支持当前最合理解释。

这是检查框架，不是固定模板。原段落已经清楚时不要为了套结构重写。

连续罗列数据和文献却没有说明关系时，补清比较、转折、条件或推理关系。先修复逻辑，再调整句子；连接词不能替代真实关系。

## 证据链与替代解释

重要机制或综合判断不应只靠一个多解指标。结合研究实际检查总体特征、局部表征、时间序列、独立测量、结构观察和系统背景是否相互支持，而不是重复同一来源。

对每个承重判断询问：

- 它对应哪项数据、图表或文献？
- 证据直接支持什么，不能支持什么？
- 比较对象、样本和尺度是否一致？
- 是否存在现实可行的替代解释？当前研究是否区分了它们？
- 反例、阴性结果或不一致研究是否会改变结论？

只讨论与当前研究实际相关的替代解释，不为显得严谨无限制造可能性。

## 避免章节间重复

Results 主要回答观察到什么；Discussion 回答为什么、支持哪种解释、与已有认识有何关系以及边界是什么；Conclusion 压缩最主要发现和含义。三处重复同一结果时，在 Results 保留必要细节，在 Discussion 转向解释，在 Conclusion 只保留核心回答。

Discussion 不能只是结果换词，也不能越过结果引入未经建立的新机制。Conclusion 不新增数据、引用或正文未讨论的观点。

## 审核问题的分级

- **确定问题**：内部矛盾、数字或对象错配、逻辑不成立、结论强度明确超过设计。
- **待确认风险**：上下文不足、可能存在替代解释、引用尚未核验或领域规则依期刊而异。

报告时给出位置、问题、影响和最小修复方案，不用笼统分数替代具体判断。
