# 有证据的正向有用结论

适用于中英文综述写作，以及已有综述稿在授权范围内的逻辑或全面润色。段落收束应优先说明读者获得了什么可靠认识。以正向有用结论至少60%、否定或局限主导的结论约40%以内为行文目标；负向结论更少时不补凑40%。比例服从真实证据、重要反证和准确的结论强度。

## 如何判断与计数

- 统计正文中承担综合判断或解释任务、并在段尾作出实质结论的段落。每段结尾的一句或连续数句合为一个收束单元，按其主导信息分类；同段不能拆成多个正向单元。正文相关讨论与局限段同样纳入，不能靠改章节标题移出统计。纯背景定义、方法说明、事实罗列和过渡段不强加结论；摘要、图注、表格、参考文献及与正文重复的全篇总结不重复计入。
- **正向有用结论（P）**：从本段证据得到明确、具体的认识，例如已经支持的关系或机制环节、适用条件、可解释的研究差异、比较所得，或有依据的研究/方法选择。允许带有必要限定；用语肯定与否、实验结果阳性与否均不能单独决定分类。
- **否定或局限主导的结论（L）**：主要停留在“不能证明”“无法实现”“证据不足”“仍需更多研究”等缺口或否定判断，没有进一步形成证据支持的具体认识。科学上必要的此类结论如实保留，不能把它自动视为写作错误。
- 含混或空泛的评价暂记为待复核（U），例如“具有巨大潜力”“提供重要启示”。统计分母为 `N = P + L + U`，待复核项不能算入正向分子或直接排出分母。目标为 `P/N >= 60%`、`L/N <= 40%`；N为0时记不适用，不报告100%。不按“不能”等关键词机械计数。

混合收束看读者最后得到的实质信息。已有具体认识并简洁注明成立条件，可归P；主导信息仍是缺口，归L。阴性结果可形成有用判断，例如有证据说明某条件下应选择哪种方法；须准确保留原阴性结果及推理依据，不能把“不支持”直接改为“有效”。

## 写作与修订

规划段落时先明确“本段证据支持什么认识”，再决定是否需要限制说明。自然选择综合判断、机制解释、条件比较或下一问题的衔接，不为每段套上相同结论句。

修订负向结尾时回读证据和前文：提炼已有但未被说清的正向认识；将重复的泛化限制合并；对确实改变结论的条件就地准确表达。研究缺口只有在能由证据推出具体可检验问题或设计选择时才形成有用建议；泛泛“今后应扩大样本”不计作正向结论。不能把缺证据包装成研究机会来提高占比。

示例只演示信息重心：若给定材料确实显示多项研究在A条件下重复观察到X与Y的关联，但没有干预验证，可用“多项研究在A条件下重复观察到X与Y的关联；这一判断目前限于关联层面”收束。没有这些实际结果时不得照抄，更不能改成“X导致Y”或声称已具有预测、诊断或应用价值。

## 回核与证据优先

在内部段落规划或编辑记录中列出段落位置、收束原句、P/L/U类别及简短理由；P指向已有主张/来源或原稿证据，L标明限制影响。合并或改写后重新回读全文，记录P、L、U、N和实际比例。对反复负向收束的小节检查原因，不要求每节精确6:4，也不通过拆分重复结论、堆砌背景或删除必要段落抬高比例。先处理U项再定稿。

低于60%时先修复可修复的表达与综合问题。若现有证据确实只能支持较多负向判断，保留这些判断，在内部记录实际比例、具体证据原因及已复核的段落；只说明真实检查结果，不伪报达标。该情况不单独把科学上完整的稿件标为未完成，也不触发补造发现、选择性删证据或擅自扩大检索范围。真正的证据缺口仍按主流程处理。

数据、结果方向、比较对象、主要终点、研究类型、因果层级和必要不确定性保持准确；尤其不能把相关写成因果，把模型结果写成人体获益，把未显著写成有效或等效。比例检查在科学与结构编辑阶段完成，内置去模板腔处理后再回核。记录属于内部编辑资料，无需在论文中增加比例声明或防御性段落。
