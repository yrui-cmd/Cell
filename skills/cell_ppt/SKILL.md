# PPT 制作

## 你需要提供

- 演示主题、使用场景、受众、预计讲解时长和希望突出的重点。
- 相关资料，例如论文题名、DOI、链接或 PDF，项目资料、数据、图表或讲稿。
- 如有指定模板、参考样例、必用内容或固定页数，一并提供。
- 确认逐页安排和对应报价。

## 你会收到

- 供确认的《逐页安排.pptx》和报价。
- 《问答与原始资料.pdf》。有参考模板时可附《精简参考模板.pptx》。
- 等待面板中的预计时间、剩余时间和订单进度。
- 最终交付的《成品ppt.pptx》，以及在 PowerPoint 编辑窗口中的成品预览。

## 本机操作

0. 每次运行先按 [PPT API 配置](references/credentials.md) 检查 Skill 内的固定凭据入口并验证余额。首次使用或密钥失效时先完成配置，再继续问答、整理资料和提交。
1. 按[逐项问答](references/nodes.md#逐项问答)，在第一次提问前先提醒客户尽量提供相关图片。每轮只问一个影响安排的问题，给一个推荐，收到回复后再问下一项。沿用已明确的答案。
2. 核对客户资料。必用论文缺全文时，先从可访问的出版社、开放仓储等来源查找并下载全文，核对题名、版本和内容完整性。取不到时再请客户提供对应 PDF。原始文件只读。
3. 用[交接工具](references/handoff.md)生成并核对逐页安排、资料 PDF 和可选参考模板，交客户确认文件版本和额度。每页安排写清要讲什么、用什么证据和讲多久。
4. 仅在确认当前文件和额度后，按[上传与等待](references/transfer.md)调用本机客户端。入队后打开聊天右侧的等待面板，展示预计时间、剩余时间和进度。重试继续同一订单。
5. 完成后按[成品回传与 PPT 输出](references/transfer.md#成品回传与-ppt-输出)下载、校验并交付《成品ppt.pptx》。将 PowerPoint 编辑窗口切到前台，在独立预览副本中每隔 0.5 秒显示一个元素，显示完当前页后自动翻页。用户手动选页时，从该页的进度继续。确认全部元素显示完成后，进度面板显示「感谢抖音：Cell-skills」。
